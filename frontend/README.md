# Mini Matrix — Wholesale Gold Monitor

## جریان دسترسی
1. **ثبت‌نام** (بدون کد)
2. **ورود**
3. وضعیت **غیرفعال** → قیمت زنده، API، خرید کابل و محاسبات قفل
4. مالک از فایل `data/activation_codes.json` / `js/codes.js` یک کد ۳۲ رقمی می‌فرستد
5. مشتری کد را وارد می‌کند → **فعال به‌مدت ۳۶۵ روز** + شمارش معکوس روز
6. هر کد **فقط یک‌بار** قابل استفاده است؛ استفاده مجدد → «قبلاً استفاده شده»

## محدودیت بدون سرور
لیست کدهای مصرف‌شده در `localStorage` همان مرورگر/دستگاه ذخیره می‌شود.
برای جلوگیری قطعی از استفاده یک کد روی موبایل‌های مختلف، بعداً به بک‌اند نیاز است.

## ساختار
- `index.html` — منو (پاسه / زیورات)
- `register.html` — ثبت‌نام · ورود · فعال‌سازی · بازیابی رمز
- `app.html` — داشبورد (قفل‌شده تا فعال‌سازی)
- `js/codes.js` + `data/activation_codes.json` — ۱۰۰۰ کد
- Twelve Data: **۸ درخواست در دقیقه**

## اجرا
پوشه را باز کنید و `index.html` را اجرا کنید.
